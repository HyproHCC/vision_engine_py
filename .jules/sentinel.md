## 2026-03-02 - Directory Traversal and Arbitrary File Read in TCP Server Endpoint
**Vulnerability:** Unsanitized `image_path` fields in `inspect` and `teach` command JSON payloads permitted directory traversal sequences (e.g., `..`) and arbitrary non-image file extensions. This allowed arbitrary file access/loading on the system (via `np.fromfile()`) or potentially copying sensitive non-image files into the public NG image directory (`ng_dir`) during defect storage.
**Learning:** The application protocol layer assumed incoming paths were safe and trusted client-side sanitization. Relying entirely on client-side safety checks leaves the backend server exposed if malicious or unexpected requests are received.
**Prevention:** Always validate all incoming file path parameters at the protocol boundary. Restrict paths to only contain allowed file extensions (.png, .bmp, .jpg, .jpeg, .tif, .tiff) and explicitly reject directory traversal sequences (e.g., `..`) before passing the paths down to any core system or file IO API.
