## 2026-03-03 - Input Validation and Path Traversal Prevention at Protocol Boundary
**Vulnerability:** The VisionEngine TCP server's `inspect` and `teach` commands accepted arbitrary file paths as `image_path` without validation, exposing the system to directory traversal (e.g. `..`) and arbitrary file format read attempts.
**Learning:** Legacy protocol layers and internal engine architectures often assume inputs are sanitized or originate exclusively from a trusted client (such as a local LabVIEW application). This assumption creates a vulnerability at the network interface boundary where an untrusted network client could attempt directory traversal or trigger arbitrary disk access.
**Prevention:** Strictly validate and sanitize all inputs at the outermost protocol parsing layer (`ve_server/protocol.py`) before handing them down to backend components or executing system-level I/O. Reject directory traversal sequences explicitly and restrict files to an allowed list of safe extensions.
